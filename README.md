## 本次学习总结

### 1. 用 Markdown 整理学习内容

- 使用标题建立清晰的知识层级。
- 使用列表记录核心概念、操作步骤与待办事项。
- 使用代码块保存可复用的命令和示例。
- 每篇笔记同时记录“学到了什么”“如何验证”“仍有哪些问题”。

### 2. 用 Git 管理学习记录

- `git init`：初始化本地仓库。
- `git add`：把本次修改加入暂存区。
- `git commit`：保存一个带说明的学习快照。
- `git status`：检查当前修改和提交状态。
- `git log`：查看学习记录的历史演进。

### 3. 用 GitHub 仓库备份笔记

- 在 GitHub 创建仓库，集中保存和展示学习记录。
- 将本地仓库关联到远程仓库后，通过 `git push` 同步。
- 后续每次完成一段学习，都以小而清晰的提交保存。

## 推荐的单篇笔记模板

```markdown
# 主题

## 学习目标

## 核心知识

## 实践记录

## 遇到的问题与解决办法

## 我的理解

## 下一步
```

## 后续维护方式

1. 每次学习结束后先写 3～5 条关键收获。
2. 补充可以复现的代码、命令或例子。
3. 写出一个仍未解决的问题，作为下一次学习入口。
4. 提交时使用具体说明，例如 `notes: summarize Git basics`。
