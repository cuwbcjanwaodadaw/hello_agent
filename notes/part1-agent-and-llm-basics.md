# 第一部分：智能体与语言模型基础

这一部分的主线是：先理解智能体的基本结构，再从发展历史理解技术路线的变化，最后掌握现代智能体的核心“大脑”——大语言模型。

## 第一章：初识智能体

智能体是一个能够**感知环境、自主决策并采取行动以完成目标**的系统。它的基本结构可以概括为：

> 环境输入 → 感知 → 思考与规划 → 选择工具 → 执行动作 → 获得反馈

智能体通过这个循环逐步推进任务，而不是一次性生成答案。按照决策方式，可以分为反应式、规划式和混合式智能体；现代 LLM 智能体通常采用混合模式，在“思考—行动—观察”的循环中兼顾规划与即时反馈。

Workflow 与 Agent 的关键区别在于自主程度：Workflow 按预先定义的固定步骤执行，适合规则明确、流程稳定的任务；Agent 只需要给定目标，能够根据环境变化动态规划和选择工具，更适合开放、复杂的任务。

## 第二章：智能体发展史

智能体的发展可以概括为一条从“人工编写规则”到“从数据和环境中学习”的路线：

1. **符号主义与专家系统**：依靠知识库、逻辑和规则进行推理，可解释性强，但存在知识获取成本高、缺少常识和规则外泛化能力差的问题。
2. **联结主义与机器学习**：知识不再完全由人手工编码，而是由神经网络从数据中学习。
3. **强化学习智能体**：通过与环境交互、试错和奖励反馈学习行动策略，适合序贯决策问题。
4. **预训练模型**：利用大规模数据学习通用知识，再针对具体任务进行调整，缓解了手工构建知识库的瓶颈。
5. **LLM 驱动的智能体**：以大语言模型作为推理与决策中枢，结合规划、记忆和工具调用，形成能够持续感知与行动的闭环。

这段历史说明：复杂智能很难依靠一套完备规则直接设计出来，更现实的路径是让系统从数据、反馈和多个模块的协作中形成能力。

## 第三章：大语言模型基础

语言模型的基本任务是根据已有上下文预测后续内容。技术路线经历了 N-gram、RNN/LSTM，再到 Transformer。Transformer 依靠自注意力机制捕捉词元之间的关系，支持并行训练并更好地处理长距离依赖。现代生成式大模型多采用 Decoder-Only 架构，通过“预测下一个词元”进行自回归生成。

与大模型交互时需要关注三个方面：

- **提示工程**：用清晰的目标、上下文、约束和输出格式引导模型；必要时加入示例或分步思考要求。
- **分词与上下文**：模型处理的是 Token 而不是自然语言原文；Token 数量会影响上下文容量、速度和成本。
- **模型选型**：需要综合权衡任务能力、成本、延迟、上下文窗口、部署方式、隐私和工具生态，而不是单纯选择参数最大的模型。

模型能力通常会随参数量、数据量和计算量扩展，但扩大规模不能自动解决所有问题。LLM 的本质仍是概率生成，因此可能出现事实错误、知识过时和偏见。构建可靠智能体时，应通过 RAG、搜索、计算器或代码执行器等外部工具补充信息，并加入结果验证、反思和人工确认机制。

## 整体理解

大语言模型提供理解、推理和生成能力；记忆保存上下文；工具扩展模型能做的事情；智能体循环负责根据反馈持续调整行动。四者结合后，系统才从“会回答问题的模型”变成“能够围绕目标完成任务的智能体”。
